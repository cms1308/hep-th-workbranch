description: Revise a project's paper with context proportional to the change, including referee responses. Use for requested manuscript edits; preserve scientific claims unless their change is authorized and supported.
---

Read `harness/PAPER-REVIEW.md` for shared context, authorization, validation and saving.
Use `PAPER-STYLE.md` for substantive prose changes. Preserve the user's intended scope.

1. Read the affected passage and the definitions and evidence it depends on. For a
   local wording edit, surrounding paragraphs and targeted searches normally suffice.
   For a change to structure or a central claim, read the whole argument and its
   abstract/introduction/conclusion echoes. Read an existing outline when useful;
   do not create a missing PUNCHLINES file before a small edit.
2. Identify the requested change and its actual dependencies: notation, equation
   references, tables, citations, or conclusions elsewhere. If the request conflicts
   with established results, explain the conflict rather than silently changing physics.
3. Apply the authorized edit and the related corrections it requires. Preserve
   intentional cuts and unrelated prose. For an incoming author copy, follow the
   comparison procedure in PAPER-REVIEW rather than assuming it is a superset.
4. Update an existing section outline only if its argument or section roles change.
   Keep affected entries accurate if a detailed map is actively used, but do not expand
   it or refresh every opening-word anchor for a routine edit.
5. Recheck changed scientific claims against records and changed citation claims against
   sources. Mark affected citation rows needing rechecking STALE; unchanged primary-source
   checks can be reused. Full audits and scans are not automatic side effects of editing.
6. Compile after manuscript/bibliography changes and check the affected references and
   layout. Record a standing decision only when the edit actually establishes one.
   Update STATE as appropriate, checkpoint, and report what changed, the relevant
   validation, and any unresolved scientific or scope issue in Korean.
